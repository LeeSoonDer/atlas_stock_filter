# TASK CARD 09 — 隐性吸筹复合信号 + 期权情报 + 质量旗标【待命卡】

> **待命卡 — 不要立即执行。** 启动条件见下方。授权:第五号修正案(修正案十五、十六、十七)。
> 启动时丢给 Claude Code,LOADED 确认后开工。

## 启动条件(满足才执行)

至少跑完 **3 至 4 个完整真实周期**(screen → Radar → 红队 → 裁决 → 账本记录)之后再启动。理由:本卡改动的是信号质量,若无运行基线,加了之后无法判断候选变好还是变坏。先有基线,再优化。

启动时可整卡执行,也可按 Part 拆分单独执行(各 Part 相互独立)。

## GOAL

用现有数据源(零新增付费依赖)精化信号质量:补齐隐性吸筹的复合画像,给候选加期权情报,增加两个质量旗标。

## SCOPE

### Part A — 隐性吸筹复合信号(src/screen/indicators 扩展)

全部为强度加分旗标,**不改变任何桶的准入条件**。

1. **RS 线时序新高** (`rs_line_new_high`)
   * 计算 个股收盘价 / SPY 收盘价 的比值时序
   * 判定:该比值创 52 周新高 **且** 个股自身价格未创 52 周新高
   * 物理含义:大盘承压期个股拒绝下跌,强手锁筹,且早于价格突破
   * 应用:挤压桶与动能桶的强度加分

2. **成交量极度干涸** (`volume_dryup`)
   * 判定:近 20 个交易日内出现过单日成交量 ≤ 50 日均量的 30%(阈值进 config)
   * 物理含义:浮动筹码枯竭,抛压耗尽
   * 应用:挤压桶强度加分(标志压缩接近末端)

3. **均价位置持续偏上** (`above_vwap_streak`)
   * 用日线近似 VWAP:典型价 (H+L+C)/3,按成交量加权滚动
   * 判定:连续 N 日(默认 5,进 config)收盘价 > 近似 VWAP
   * **诚实标注**:代码注释与字段说明必须写明这是日线近似,非真实分钟级 VWAP
   * 应用:全桶通用强度加分

4. **内部人买入加权** (`insider_cluster` 升级)
   * 现行人头计数改为加权评分:
     - 职位权重:CEO/CFO/COO = 2.0,其他高管 = 1.5,董事 = 1.0
     - 金额显著性:单笔 ≥ $100k 再乘 1.5(阈值进 config)
   * 集群判定改为加权分达阈值,而非单纯人数
   * 仍严格限定 Code P(公开市场买入),排除 Code M / Code A


5. **ADX 趋势强度** (`adx14`)
   * 标准 ADX(14)计算
   * 判读:>25 有趋势,<20 震荡区间
   * 应用:动能桶强度修正——ADX<20 时该候选标记 `range_bound_warning`,
     提示"满足突破条件但趋势强度不足,可能是震荡区间上沿"
   * 理由:趋势策略在震荡市被反复打脸,此旗标区分真突破与震荡到顶

6. **回踩型子标记** (`entry_structure`)
   * 对动能桶命中标的,区分两种结构:
     - `breakout`:价格贴近 52 周高或刚突破前高
     - `pullback_to_ma`:趋势确立(均线多头)但价格回踩至 SMA20/50 附近且缩量
   * 理由:回踩型的风险收益通常优于追突破型;Radar 需要知道这只票是"追高位"
     还是"接回踩",风险讨论才准确
   * 应用:仅作结构标记,不改变桶判定

7. **候选集中度警示** (`concentration_warning`,run 级)
   * 统计本批候选与观察哨中,同板块或同主题标的数量
   * 若某板块/主题 ≥3 只,run 元数据标记该主题名与数量
   * 理由:主题雷达会自然导致候选集中于同一板块,同时持有多只等于单一头寸放大,
     而非分散。此为系统自身机制带来的风险,必须显式提示
   * **边界**:仅陈述集中事实,严禁给出任何仓位建议(仓位属人类领地)

### Part B — 期权情报(候选池限定)(src/data/options)

**严格边界:仅对候选与观察哨(≤15只)抓取,严禁全宇宙扫描。**

1. 用 yahoo-finance2 期权链,对每只候选计算:
   * `volume_oi_ratio_max`:各行权价中,当日成交量/未平仓量的最大值(>3 标记异常)
   * `near_otm_call_oi`:近月、价外 15至30% 的看涨期权未平仓总量,及其相对该股历史水平
   * `put_call_ratio`:全链看跌/看涨比,及较上次运行的变化
   * `iv_move`:平值隐含波动率较 20 日均值的变化
2. **硬性边界(代码层强制)**:
   * 期权字段**严禁参与任何桶判定或候选选取**,只写入 payload 的情报区
   * 字段命名与注释必须标明这是**汇总数据,无买卖方向、无逐笔、无交易主体**
   * 严禁在应用层生成任何"巨鲸押注""内幕信号"类表述(grep 验证)
3. 数据不可得时标 `[不可得]`,不阻塞

### Part C — 质量与稀释旗标(src/screen/fundamentals 扩展)

1. **应计质量旗标** (`accrual_quality`)
   * 计算:(净利润 − 经营活动现金流) / 总资产
   * 超阈值标 `accrual_flag: true`
   * **旗标,不淘汰**(成长与反转类天然应计偏高)

2. **现金跑道旗标** (`cash_runway_months`)
   * 仅对 SMALL_SPEC 档标的计算:现金及等价物 / 过去12个月平均现金消耗速率
   * < 12 个月标 `dilution_risk: true`
   * **旗标与警示,不淘汰**(维持"旗标不淘汰"既定裁决)
   * 数据缺失标 `[不可得]`,不惩罚

# TASK CARD 03 — 基本面旗标 + 板块强度 + 市场环境快照

> LOADED 确认后执行。前置:CARD 02 验收通过。

## GOAL

为每个候选补齐基本面旗标(不淘汰,备忘录四 B8)与板块相对强度,并产出全局市场环境快照供 payload 使用。

## SCOPE

1. **基本面旗标**(src/screen/fundamentals,yahoo 数据):
   * 营收同比增速旗标(加速/平稳/减速/负增长)
   * 毛利率方向旗标(近两期改善/恶化)
   * 盈利状态(盈利/亏损收窄/亏损扩大)
   * 现金与债务粗检(净现金/可控/高杠杆)
   * 财报临近旗标(未来 14 日内有财报 = `earnings_soon: true`,重要风险信息)
   * 数据缺失一律 `[不可得]`,不惩罚不淘汰
2. **板块强度**(src/screen/sector):
   * 11 个 SPDR 板块 ETF 的 1 月与 3 月收益率排名
   * 每标的标注所属板块及该板块当前排名(前三 = 顺风,后三 = 逆风)
3. **市场环境快照**(src/screen/regime),运行级一次计算:
   * SPY 相对 SMA 200 位置与斜率
   * VIX 当前值与 20 日均值
   * 领涨与领跌板块
   * 合成一行环境标签(顺风/中性/逆风,规则写注释)——仅描述,不改变筛选行为
4. 旗标全部并入 screen_run JSON 的每标的对象与 run 元数据

## DONE-WHEN

* [ ] 抽查 5 只:基本面旗标与 yahoo 页面数据一致
* [ ] 财报临近旗标经财报日历核对无误
* [ ] 环境快照三要素齐全且有环境标签
* [ ] 缺数据标的正常通过,带 `[不可得]` 标注

## MUST-NOT

* 用基本面淘汰任何标的;LLM;机构数据(下一卡)

# TASK CARD 08 — 环境防御闸(立即执行:信用熔断 + 最低股价闸 + 市场宽度)

> 丢给 Claude Code。LOADED 确认后开工。前置:CARD 01 至 06 已上线。授权:第五号修正案(修正案十四、十七最低股价闸部分)。
> **本卡为立即执行卡** — 纯防御性,不改变筛选逻辑,不需要运行基线即可判断价值。

## GOAL

给系统装三道环境防御:信用环境熔断(保护 SMALL_SPEC)+ 最低股价闸(排除交易摩擦标的)+ 市场宽度(读取猎场真实健康度)。

## SCOPE

### Part A — 信用环境熔断(src/screen/credit_regime)

1. FRED 拉取高收益债 OAS(序列 `BAMLH0A0HYM2`,FRED 已在数据源,复用现有 client)
2. 计算三态判定(阈值进 `config/credit.json`):
   * `loose`:OAS < 350bp 且近两周下行
   * `tight`:OAS > 450bp,**或** 近两周发散上行 > 50bp
   * `neutral`:其余
3. **收紧态强制行为**:
   * SMALL_SPEC 档自动禁用(即使用户命令行指定 `--profile both` 或 `small_spec`,也强制跳过并在终端与报告中说明原因)
   * 报告顶部渲染红色信用收紧警示条
   * 全部候选的 `risk_level` 自动上调一级
4. 判定结果并入 run 元数据与 payload 的环境快照

### Part B — 最低股价闸(src/universe 扩展)

1. STANDARD 档:收盘价 ≥ $5
2. SMALL_SPEC 档:收盘价 ≥ $1
3. 阈值进 `config/profiles.json`,与现有市值/成交额闸并列


### Part C — 市场宽度(src/screen/breadth)

宽度衡量市场内部健康度,与指数层面(SPY/VIX)是不同维度的信息。指数创新高但宽度背离,
意味着上涨由少数权重股支撑,广大个股在阴跌——此时动能桶与挤压桶的候选假突破率显著上升。
Atlas 筛的是全市场三千只(多为中小盘),宽度才是猎场的真实天气。

1. 复用已有的全宇宙均线计算,聚合统计:
   * 站上 200 日均线的标的百分比
   * 站上 50 日均线的标的百分比
   * 创 52 周新高家数 vs 创 52 周新低家数(及其比值)
2. 宽度状态判定(阈值进 config/breadth.json):
   * `healthy`:>55% 站上200线,且新高多于新低
   * `narrowing`:35% 至 55%,或新高新低接近
   * `weak`:<35% 站上200线,或新低显著多于新高
3. **背离检测**:SPY 处于 200 线上方但宽度判定为 weak → 标记 `breadth_divergence: true`,
   报告顶部警示"指数强但内部弱,个股突破可靠性下降"
4. 并入 run 元数据与 payload 环境快照
5. **边界**:只描述当前宽度状态,严禁据此预测大盘走向

## DONE-WHEN

* [ ] 宽度数据并入环境快照

## MUST-NOT

* 用信用数据做任何市场方向预测(只读当前状态调整系统行为)
* 改动任何桶的判定逻辑
* LLM 调用

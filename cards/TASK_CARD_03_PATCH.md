# TASK CARD 03-PATCH — 板块资金足迹聚合 + 事件窗口旗标

> append-only 补丁,不改动 CARD 03 已定范围,新增两个能力。前置:CARD 03 与 CARD 04 均验收通过(板块聚合依赖 CARD 04 的机构桶数据)。授权来源:第三号宪法修正案。

## GOAL

给系统装上"赛道级资金雷达"与"催化剂日历",回答两个新问题:钱是不是在悄悄流进某个板块?哪些候选近期有确定性催化剂窗口?

## SCOPE

### Part A — 板块资金足迹聚合(src/screen/sector_footprint)

1. 个股四桶检测完成后,按 11 个 SPDR 板块分组
2. 每板块计算四个密度指标:
   * 机构蓄势桶命中数 / 板块有效标的数
   * 内部人集群(insider_cluster)标的密度
   * 做空余额显著下降标的密度
   * 波动挤压蓄势标的密度
3. 异动判定(阈值进 config/sector.json):
   * 简单法(v1 用这个):某密度 ≥ 全板块该密度中位数的 2 倍,且绝对数 ≥ 3 只
   * 命中即标记该板块 `footprint_anomaly: true`,记录触发的是哪个密度维度
4. **诚实边界硬编码:** 输出字段只允许陈述事实(密度数值 + 触发维度),代码层禁止生成任何方向性文字。注释写明此为宪法约束
5. 并入 run 元数据

### Part B — 事件窗口旗标(src/screen/event_window)

1. 扩展 CARD 03 已有的财报临近旗标为完整 event_window:
   * 财报日(yahoo/Finnhub 财报日历)
   * 锁定期解禁日(若 IPO 标的,profile 可得则算)
   * 已公告的股东大会/产品发布(尽力而为,不可得则跳过)
2. 落入未来持有周期窗口内的事件 → `event_window` 对象:{类型, 日期, 距今天数}
3. **边界硬编码:** 只登记日程事件,不预测结果。注释写明

## DONE-WHEN

* [ ] 全量运行后,板块聚合产出 11 板块密度表
* [ ] 人工构造一个测试板块(塞入多只机构桶标的),验证 footprint_anomaly 正确触发
* [ ] 抽查 3 只有财报临近的候选,event_window 日期与财报日历一致
* [ ] 输出中无任何方向性预测文字(grep 检查:无"将上涨/看好/下一个热点"类词)
* [ ] 板块异动与事件旗标均进入 HTML 报告(顶部横幅 + 候选卡高亮)与 PAYLOAD

## MUST-NOT

* 任何赛道预测、价格预测、买入建议
* 预测非日程性突发消息
* LLM 调用

## 熔断

同卡点失败 2 次 → 停止,升级包。板块聚合数据不足时(如某板块标的太少)降级为跳过该板块而非硬撑。

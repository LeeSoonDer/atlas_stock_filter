# TASK CARD 02 — 技术检测器三桶:动能突破 / 波动挤压蓄势 / 超卖反转

> LOADED 确认后执行。前置:CARD 01 验收通过。

## GOAL

实现四桶中的三个纯技术检测桶,`npm run screen` 输出中每个通过标的附带完整技术旗标与所属桶判定。

## SCOPE

1. **指标库**(src/screen/indicators):基于 CARD 01 的 OHLCV,纯函数实现:
   SMA 20/50/200、RSI 14、ATR 14 与 ATR%、52 周高低与当前位置百分比、成交量 50 日均值与量比、OBV 及其 20 日斜率、Bollinger 带宽及其 120 日百分位、RS 相对强度(3 月与 6 月收益率在当日全宇宙内的百分位排名)
2. **Detector A 动能突破**(全部满足):
   * 收盘价 ≥ 52 周高点的 95%
   * SMA 排列 20 > 50 > 200 且价格在 20 上方
   * 突破日或近 5 日内量比 ≥ 1.8
   * RS 6 月百分位 ≥ 80
3. **Detector B 波动挤压蓄势**(埋伏型,全部满足):
   * BB 带宽百分位 ≤ 20(120 日窗口)
   * 价格距 52 周高点 ≤ 15% 或横向基底 ≥ 30 个交易日
   * 基底期内量能萎缩(近 20 日均量 < 50 日均量)
   * 价格 ≥ SMA 200
4. **Detector C 超卖反转**(全部满足):
   * RSI ≤ 30(SMALL_SPEC 档 ≤ 25)
   * 52 周位置 ≤ 30%
   * 近 10 日出现单日量比 ≥ 2 的止跌放量,或 OBV 20 日斜率转正(背离旗标)
   * 流动性仍达档位闸
5. 全部阈值进 config/detectors.json,零硬编码
6. 输出:每标的 `flags` 对象(全指标数值)+ `buckets` 数组(命中的桶,可多桶)+ 桶内原始强度分(该桶核心指标的简单合成,仅用于桶内排序,算法写注释)

## DONE-WHEN

* [ ] 全量运行后三桶各有非零命中(市场极端状态除外,输出需说明)
* [ ] 抽查每桶 3 只,人工对照 TradingView 图形,判定合理
* [ ] 指标函数有单元测试(用固定 OHLCV fixture,验证 RSI/SMA/带宽计算正确)
* [ ] 阈值全部可在 config 修改并生效

## MUST-NOT

* 机构数据、基本面逻辑、排名选取、LLM

## 熔断

同卡点失败 2 次 → 停止,升级包。

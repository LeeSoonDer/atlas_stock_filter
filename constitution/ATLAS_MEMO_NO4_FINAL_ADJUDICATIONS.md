# Atlas 第四号裁决备忘录（开发冻结前最终裁决）

## 引言

本备忘录记录项目所有者在开发启动前最后一轮全面问询（A1 至 F21）的正式裁决。本备忘录与既有三份宪法文件冲突之处，以本备忘录为准。至此，Atlas v1.1 开发基线彻底冻结 = v1.0 蓝本 + 第二号修正案 + 第三号备忘录 + 本备忘录。

* * *

## 一、定位与期望管理（A1 至 A4）

* **系统链定位**：Atlas 承担挖掘与提前发现职能，Cockpit 承担个股深研职能，两系统串联构成完整研究漏斗。Atlas 的宪法使命维持注意力配置引擎口径不变。
* **期望管理条款**：系统承诺的是过程质量（筛选纪律、证据收敛、假阳性防御、前向验证），不承诺收益。中短期爆发是研究对象与筛选目标，不是合同产出。本条为对使用者本人的诚实保护条款。
* **运行节奏**：筛选按需触发，每周至少一次，允许每周多次。第三号备忘录 Q2 的固定每周一次条款废除，替换为按需模式。每次运行的数据以运行时点快照为准，报告强制标注数据时间戳。
* **时区权重**：三个法定时区（1至2周、1至2个月、3至6个月）全部平权支持，候选按各自机会类型自然归属时区，不设主轴倾斜。
* **第二系统独占位**：确认。其他候选方向（财报系统、VGC、地产）全部搁置。

## 二、筛选逻辑（B5 至 B9）

* **v1 机会类型检测器（四桶）**：
  * 动能突破（Momentum Breakout）：已发动的强势标的
  * 波动挤压蓄势（Volatility Compression Setup）：未发动的埋伏型标的
  * 机构蓄势代理（Institutional Accumulation Proxy）：内部人集群与持仓趋势驱动
  * 超卖反转（Oversold Reversal）：极端错杀候选
  * 其余四类（叙事重定价、基本面重定价、行业轮动、宏观顺风）保留接口，v1 不实现。叙事识别归研究层职责（网络检索为研究层原生优势）。
* **两级产出制（新设）**：
  * **候选级（Candidates）**：每次运行至多五个，四桶轮询选取，进入研究层推理
  * **观察哨级（Watchlist）**：每次运行至多十个，主要收纳挤压蓄势型与临界未达标标的，仅由应用层追踪状态变化（挤压释放、旗标翻转），不消耗任何推理资源。观察哨标的在后续运行中触发条件时自动升格为候选
* **双档宇宙制（新设）**：应用层支持运行档位选择：
  * `STANDARD` 档：市值 ≥ 3亿美元、日均成交额 ≥ 500万美元
  * `SMALL_SPEC` 档：市值 5000万至3亿美元、日均成交额 ≥ 100万美元，输出强制附加投机级风险标注
  * 两档可单独或合并运行，由用户在运行时选择。宪法禁入清单（OTC、SPAC、杠杆反向基金等）对两档同等生效
* **基本面处理**：一律旗标制，不作淘汰闸。困境与反转类机会天然携带恶化财务，硬闸会系统性杀灭整类机会。

## 三、研究层（C10 至 C12）

* **候选辩护状制（宪法级修改）**：v1.0 十四板块刚性报告结构对 Atlas 停止适用。Atlas 研究层的法定交付物为单页候选辩护状（Candidate Brief），刚性结构由辩护状模板定义（见 Atlas Radar 指令文件）。终局摘要卡片的全部最低字段要求维持不变。全深度研究属 Cockpit 领地。
* **红队实质性分级制（新设，回应错杀关切）**：红队严禁为反对而反对。红队裁决必须落入以下四级之一，且任何攻击必须挂载具体证据或具体逻辑缺口，禁止通用风险陈述：
  * `THESIS BROKEN`：存在证据性致命伤，设想应废弃
  * `MATERIAL RISK`：存在实质性风险，设想存续但确信度必须下调
  * `MINOR FRICTION`：存在次要摩擦，记录即可，不强制调分
  * `NO EFFECTIVE ATTACK`：红队未能构造有效攻击，此为合法且有信息量的产出
  * 通用市场风险（大盘可能下跌、宏观不确定等）不构成有效攻击。红队的唯一职责是找出该标的特异性的证伪路径与无效化条件，而非证明世上存在风险。
* **批量证据包制**：单次运行的全部候选合并为一份研究层证据包，一次递交产出全部辩护状。红队同样接收单份批量包（仅含各候选的设想陈述与摘要卡，严禁附带正方推理过程），在包内逐候选独立分节攻击。

## 四、工程（D13 至 D16）

* **技术栈**：TypeScript CLI 为 Layer 1 核心，数据管线复制自 Cockpit。
* **周报形态**：每次运行产出机器可读 JSON 与人类可读自包含 HTML 报告（单文件、内嵌样式与迷你图形、浏览器直接打开）。未来独立仪表盘（Next.js + P4 设计宪法）列为可选任务卡，非 v1 必需。
* **回填机制**：不建提醒系统。HTML 报告尾部被动列出已到期与已触发无效化的账本条目，回填动作归入月度复盘仪式执行。
* **宪法变更流程**：修正案与备忘录直接提交并打 git tag，不设合并请求流程。

## 五、数据源（E17 至 E19）

* **FMP 限额策略**：全宇宙筛选仅使用 Yahoo 数据源；FMP 仅在候选与观察哨确定后，对至多十五个标的执行二次充实与双源校验。
* **13F 排期**：v1 以 Form 4、机构持股比例趋势、做空余额为机构证据主体。EDGAR 13F 增量解析独立为延后任务卡，无限期后置，不阻塞任何主线。
* **误杀容忍**：启发式禁入过滤的误杀率在百分之二以内不作修复。

## 六、校准仪式（F20）

* **月度复盘制**：每月执行一次十五分钟复盘，固定三问：本月哪一桶候选死亡率最高；红队的哪些攻击被现实验证；下月是否修改一个参数（至多一个，允许不改）。复盘结论写入账本，参数修改打 git tag。
